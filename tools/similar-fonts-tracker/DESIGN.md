# Design

<!-- impeccable:design-schema 1 -->

This is a dark, desktop-first spreadsheet with two tabs: Creative Market and Creative Fabrica. Each tab shows one plain table with ten larger rows per page and simple previous/next controls. The Creative Market sheet places the prepared name beside the source name, followed by product and Similar Fonts links, green/red Similar marks, and green/amber Dealt marks that appear only after a red Similar mark. The Creative Fabrica sheet contains the source font, prepared name, source-match link, prepared listing link, and green/amber Dealt marks that appear only when a source-match link exists. Keep the interface to tabs, table, pagination, links, and marks; do not add dashboards, counters, filters, or explanatory panels.
