# Troska Evaluation

Generated on 2026-09-03 from:

- `Troska.otf` as the clean display face;
- `Troska Stamp.otf` as the distressed display face;
- `/usr/share/fonts/TTF/DejaVuSans.ttf` for small neutral labels.

## Image Set

- `thumbnail_main.png`: product-led cover with both styles;
- `promo_1.png`: oversized race/repeat headline composition;
- `promo_2.png`: modular retro racing layout with stamp treatment;
- `promo_3.png`: direct Regular versus Stamp comparison;
- `promo_4.png`: uppercase, lowercase, numerals, and OpenType study.

Each composition is authored separately for 1500x1000 and 1000x1000. The
square set is not cropped or derived from the landscape set.

## Result

The rendered output is suitable as a proof of concept for the proposed
typography-led workflow. It preserves the real font outlines, produces stable
repeatable pixels, and reaches the same general visual language as the
typographic portion of YouWorkForThem-style product previews: oversized type,
limited palette, grid rules, technical labels, and controlled print wear.

The current limitation is art direction, not rendering. These four compositions
are hand-authored Troska evaluation examples, not reusable templates and not a
production default. New fonts must be directed and authored individually by
the registered Agent 27 workflow; this prototype intentionally does not create
a font package, run Agent 13, or place files in `prepared_visuals/`.
