# Pinterest board setup

Use these exact board names so they match the `Board Name` values in Buffer's
Pinterest CSV. Paste each description into the board's Description field in
Pinterest. Keep each board public and focused on the type styles and projects
named here. The descriptions give visitors and Pinterest context about the
collection.

| Board name | Description |
|---|---|
| Display Fonts for Logos & Posters | Bold display typography for logos, posters, packaging, headlines, and brand identity. |
| Script & Handwriting Fonts | Script, calligraphy, signature, and handwritten fonts for invitations, stationery, quotes, and personal branding. |
| Serif Fonts for Branding & Editorial | Modern, elegant, vintage, and high contrast serif fonts for branding, packaging, and editorial design. |
| Retro & Vintage Fonts | Retro, groovy, vintage, and western type for nostalgic posters, apparel, labels, and branding. |
| Gothic & Blackletter Fonts | Gothic, blackletter, medieval, and dark display typography for logos, posters, and alternative projects. |
| Pixel, Gaming & Tech Fonts | Pixel, arcade, futuristic, and cyberpunk fonts for gaming, digital art, and tech projects. |
| Cricut & Craft Fonts | Font ideas for Cricut projects, vinyl, apparel, decals, signs, cards, and DIY lettering. |

To add or edit a description, open the board in Pinterest, choose **Edit
board**, update its Description field, and save. [Pinterest board editing
guide](https://help.pinterest.com/en/article/edit-a-board).
