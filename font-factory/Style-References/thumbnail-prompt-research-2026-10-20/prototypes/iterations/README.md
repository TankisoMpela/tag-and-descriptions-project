- [`pre-subtitle-refresh/`](pre-subtitle-refresh/) contains the nine previous current images, saved before the descriptor lines and Silken Flourish redesign.
- [`round-1-current/`](round-1-current/) contains the four designs replaced during the earlier reference review.
- [`low-key-refresh/`](low-key-refresh/) contains five premium/photo-heavy versions replaced with lettering-led designs. Its `flat-first-pass/` and `rejected-after-feedback/` subfolders keep superseded design trials out of the gallery.
- Other PNGs in this folder are prior working attempts, including rejected overlap or layout variations.

Archived images are retained for comparison and are not shown as current designs in the gallery.
