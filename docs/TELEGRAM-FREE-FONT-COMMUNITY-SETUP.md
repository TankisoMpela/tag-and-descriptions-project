# Telegram Free Font Community

## Recommended structure

- **Public channel:** official free-trial-demo announcements, download links,
  release notes, and Commercial Use upgrade links.
- **Discussion group:** optional questions, feedback, and troubleshooting.
- **Pinned post:** demo scope, non-commercial restriction, redistribution rule,
  BOOTH link, and contact/support details.

## Launch checklist

1. Create the channel and reserve a short, brand-consistent username.
2. Link a discussion group only if moderation time is available.
3. Add the pinned license and download guidance before the first campaign.
4. Use one post template for every font: name, included scope, exclusions,
   download link, and Commercial Use link.
5. Never collect font files, customer data, or credentials through the group.

The agents prepare Telegram-ready announcement copy; they do not create the
group, publish messages, or manage members.
