# Font Supporting Image Templates

Use this skill for the shared reference-led supporting-image catalogue. Read
`font-factory/support-references/TEMPLATE-GUIDE.md` before changing or
rendering a layout. The guide owns each reference's required copy, composition,
assets, flexible fields, and captions.

## Work in the existing catalogue

- Edit templates in `font-factory/support-html/` and use its editor and renderer.
- Keep each reference layout one-to-one with its documented adaptation.
- Build 3:2 and 1:1 as separate compositions; do not stretch, pad, or crop one
  ratio into the other.
- Preserve locked subject matter, copy, palette, and hierarchy. Change only
  fields the guide marks as flexible.
- Use the actual supplied font and keep all visible words in their specified
  case. Do not add the product font name to support artwork unless requested.

## Visual restraint

Keep the source design's visual idea clear. Do not add glitter, sparkles,
starbursts, confetti, floating particles, excessive microtexture, gratuitous
glow, generic AI ornament, or extra details that compete with the type. Keep
the title readable, avoid collisions and clipping, and use whitespace with
purpose.

Use the catalogue's existing renderer and QA commands. Do not start a separate
one-off artwork workflow when the matching shared template already exists.
